# 04. 画面遷移

```mermaid
flowchart TB
    Start([アプリ起動]) --> First{初回起動?}
    First -- はい --> Explain["権限の説明（1枚）<br/>Bluetooth（近くのデバイス）と通知"]
    Explain --> Dialog["権限の許可ダイアログ"]
    Dialog --> List
    First -- いいえ --> List

    List["① 一覧（メイン）<br/>全部ON / 全部OFF<br/>デバイスカード（別名・LHB-名・状態・最終確認時刻・トグル）<br/>0台なら「デバイスを追加」"]
    List -. "Bluetooth 権限なし" .- Banner["一覧の上に案内<br/>「設定を開く」→ 設定アプリ（アプリ情報）"]
    List -- "カードをタップ" --> Detail

    List -- "＋ / デバイスを追加" --> Scan["② デバイス追加（スキャン）<br/>LHB- / HTC BS で始まるものだけ<br/>登録済みはグレーアウト"]
    Scan -- "タップで登録（2.0）" --> Detail["デバイス詳細<br/>状態・個別トグル / 別名 / 「点滅させる」= Identify に 0x00（2.0 のみ）<br/>本体IDの入力・変更（1.0 のみ）<br/>このデバイスのログ（状態遷移など）/ 削除（確認あり）"]
    Scan -- "タップ（1.0）" --> AskId["本体IDの入力ダイアログ（任意）<br/>8桁 / 先頭4桁 / 空"]
    AskId -- "登録" --> Detail
    AskId -- "キャンセル" --> Scan
    Detail -- "保存 / 戻る / 削除" --> List
    Scan -- "戻る" --> List

    List -- "⚙" --> Settings["③ 設定<br/>タイムアウト秒数（10〜180）<br/>アプリのバージョン"]
    Settings -- "ログ閲覧" --> Log["ログ<br/>接続・書き込み・リトライ・状態遷移"]
    Log --> Settings
    Settings -- "戻る" --> List
```

- 初回だけ権限の説明画面を挟む。通知を拒否されても先に進め、処理も動く
- 説明画面は許可・拒否どちらでも一度通れば二度と出さない
- Bluetooth の権限が拒否されている間は、一覧の上に案内と「設定を開く」（設定アプリのアプリ情報）を出す。設定アプリから戻ると反映される
- 登録はタップした時点で行い、詳細画面で別名を保存せずに戻っても登録は残る
- 詳細画面は登録直後と一覧のカードタップで同じものを開く（登録後も点滅で実機を確かめながら別名を変えられる）
- 1.0 は登録前に本体IDを聞くが、空のままでもよい（スリープを確実にしたい人だけ入れる）。あとから詳細画面で入力・変更できる。1.0 には Identify がないので点滅ボタンは出さない
